Hangman
-------

Jules Gates
10/28/2026

- Hardcode the Hangman phrase to be "No pain, no gain."
- Allow the user to enter upper or lower case and convert to upper case.
- For this problem, assume the player will not guess the same letter more than once.
- If the user guesses a letter of the phrase, print "Good guess!" and show the phrase with that letter revealed. 
- If a user guesses a letter not in the phrase, print "Sorry!" and show that letter as one of the bad guesses.
- Allow six bad guesses.
- The game ends when either 
  - They run out of bad guesses: print "You lose!"
  - They guess the phrase: print "You win!", 
- When the game ends, print the phrase.
